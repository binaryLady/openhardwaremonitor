Windows — the full application

The desktop app: WinForms GUI, ring-0 sensor drivers (temperatures, fans, voltages, clocks, loads), and this dashboard served built-in at localhost:8085.

  1. Download the OpenHardwareMonitor artifact from the latest windows build run (GitHub sign-in required for artifact downloads).
  2. Unzip and run OpenHardwareMonitor.exe as Administrator.
  3. Enable Options → Remote Web Server → Run.
  4. Open http://localhost:8085/ — this dashboard, live.

macOS — the agent

A dependency-free Node agent serves this dashboard and your Mac's sensors. Out of the box: CPU load, clocks, memory, battery temperature & charge. brew install smctemp adds CPU/GPU temperatures; sudo adds powermetrics fidelity (die temperature, fans, package power). Nothing is faked — each tier reports only what it can read.

git clone https://github.com/binaryLady/openhardwaremonitor.git
cd openhardwaremonitor
node agent/serve.js --open

Start at login: node agent/serve.js install (writes a launchd agent; uninstall reverses it).

Linux — the agent

The same agent, reading every temperature and fan the kernel exposes in /sys/class/hwmon — no root needed.

git clone https://github.com/binaryLady/openhardwaremonitor.git
cd openhardwaremonitor
node agent/serve.js --open

Start at login: node agent/serve.js install (systemd user unit).

On the map

The agent also serves a live SpaceAPI fragment at /spaceapi — activity as state.open, temperatures and fans as sensors, fresh on every request. Register that URL on Maps of Making and the machine is a living space signal.
